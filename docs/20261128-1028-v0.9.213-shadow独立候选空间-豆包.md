# v0.9.213 shadow 独立候选空间

## 结论

v0.9.213 把 addon 长句（`compactPinyin >= 54`）切到独立 shadow 候选空间：候选生成、显示、翻页、数字键、点击、Ctrl+←/→、空格提交全部走 `shadowCands_`，不再把 shadow 首选塞进主候选列表。

addon 真实上屏 1200 句：**Top1 30.92%→31.75%（371→381 句，+0.83pp）**，字级 86.45%→86.34%（-0.11pp），Top5 46.17%→45.17%（-1.00pp），P95 603.9ms→788.9ms。

分域 Top1：baike 31.0→32.67（+1.67pp）、news 40.33→40.33（持平）、recent 33.33→35.67（+2.34pp）、wiki 19.0→18.33（-0.67pp）。

净增益成立，但代价是 Top5 下降 1pp、wiki 回退 2 句、P95 增加约 185ms。是否继续保留以 Top1 为主目标判断：**保留**。

## 实现

1. `PinyinIMEEngine::ensureShadowIME()` 惰性创建第二个 `libime::PinyinIME`，独立 `PinyinDictionary` + `UserLanguageModel`，`setNBest(60)`；只在首次长句输入时加载。
2. `PinyinIMEState` 增加 `shadowCtx_`（持久 `PinyinContext`）与 `shadowTyped_`。跨过 54 字母时整串 type 一次，之后每键只增量 type 新字符；退格/消歧导致前缀不符时整串重建。
3. `shadowRerank()` 只读 shadow context：过滤覆盖整串拼音的候选，按 `base + 0.25*CharLM + 0.4*单字词数` 重排，沿用 `1.0` 门限软降权，取前 60 条。
4. `updateUI()` 在 shadow active 时直接构建 shadow 候选列表（每页 5，索引为全局 shadow 下标），不混入主 context、boost、云候选。
5. `selectCandidate()` 最前面处理 shadow：按 `shadowCands_[idx]` 直接提交，记入撤回栈，然后清空 shadow。
6. Ctrl+←/→ 的候选焦点范围改为按 `shadowCands_` 计算；翻页仍用 `maxPage_`，数字键/鼠标点击复用 `selectCandidate()`。
7. 评测转储 `dumpEvalCandidates` 在 shadow active 时导出 shadow 前 20 条，否则 Top-k 仍会读主 context，指标与真实显示不一致。
8. `reset()`、提交、退格、撤回恢复都会清/重建 shadow 状态；`shadowDirty_` 在每次拼音变化时置位。

## 关键弯路

- 第一版每键都新建 `PinyinContext` 整串重放：单句 P50 约 500ms，xdotool 连续输入时事件积压，空格提交超时，400 句 Top1 0.5%、大量句子把上一句文本带入。**不能每键整串解码**。
- 改成持久 shadow context（阈值处整串一次，之后增量）后，400 句恢复到 32.25%，P50 490ms；全量 31.75%。
- 候选池 100 对 400 句 Top1 无变化（129/400），wiki Top5 仅 +1 句，P95 反而升到 1.0s，回退 60。
- shadow 单字词 β=0.2：400 句 Top1 31.75、Top5 46.75，相对 β=0.4 的 32.25/46.5，Top1 降 2 句换 Top5 +1 句，不采用。

## 风险与未做

- wiki 专名是 shadow 的弱项：NBest60 内实体覆盖不足，wiki 19.0→18.33；NBest100 也没救回来。
- Top5 从 46.17 降到 45.17：shadow 只保留 60 条且重排后正确句可能排到 6～10，Top10 反而 49.75→49.92。
- P95 788.9ms：首次跨 54 字母要整串解码一次；eval 每键 5ms 时会排队，真实用户 120ms/键通常无感。
- shadow 提交不调用 `context_.learn()`，长句选择不进入用户词频；主 context 仍保留拼音，撤回可恢复。
- shadow 分支不接云候选、简拼 boost、emoji；长句场景本身不需要，但属于行为差异。
- 第二份 LM 只在长句首次使用时加载，内存约翻倍；未做长期内存/启动测试。
