- 日期：2026-10-15
- 机器：114.116.247.146（openEuler 22.03 LTS aarch64，只读 /usr 沙箱，无 conda/docker，root 但无 CAP_SYS_ADMIN）
- 版本：v0.9.95（VERSION / fcitx5-addon/CMakeLists.txt）
- 前置：v0.9.94 已打通 X 图形层（Xvfb + LD_PRELOAD xkbcomp 垫片 + XIM）

## 1. 结论先行：这不是 CLI

本项目的交付物是 **fcitx5 的输入法 addon `libpinyinime.so`**，与搜狗拼音、`fcitx5-pinyin` 使用**完全相同的框架**（fcitx5 + libime）。`pinyin-ime` 命令行只是调试用旁路。v0.9.94 已经验证到 X11/XIM 图形层；本版进一步**在真实 X 应用窗口里截取"打拼音 → 候选窗 → 空格上屏中文"的全过程**。

## 2. 演示做了什么

脚本 `scripts/xvfb_gui_demo.sh`：

1. 起 Xvfb 虚拟显示（带 xkbcomp 垫片）、DBus、fcitx5（XIM 前端 + pinyinime addon，classicui 候选窗）。
2. 运行 `tools/ime_gui_demo.c`：一个**真实 X 客户端窗口**（白底；用 **libXft + fontconfig + 文泉驿** 渲染中文）。
3. XTest 注入按键，客户端用 `XFilterEvent` 把按键转发给 XIM；fcitx5 pinyinime 出候选、上屏。
4. 上屏文本经 `Xutf8LookupString` 取回并渲染到窗口；每个阶段抓整屏（`XGetImage` → PPM），再 PPM→PNG（python zlib 自写最小 PNG 编码器）。

## 3. 关键坑：候选窗为什么不出现

第一次跑时两张截图一模一样（只有白窗口），**没有候选窗**。

**根因**：XIM 协议下，输入法（fcitx5）**只能看到客户端通过 `XFilterEvent` 过滤过的按键**。初始版本只 `XTestFakeKeyEvent` 注入按键，却没有把事件队列里的 KeyPress 交给 `XFilterEvent`，因此 fcitx5 完全没收到输入，自然不会出候选。

**修复**：每次发键后泵一次事件队列（`XNextEvent` + `XFilterEvent`），并在等待候选窗绘出期间持续泵事件。

## 5. 新增依赖（sysroot，`dnf download` + `rpm2archive` + `tar` 解包，**不 install**）

- CJK 字体：`wqy-microhei-fonts`、`wqy-zenhei-fonts` → `/workspace/sysroot/usr/share/fonts/`。
- 编译 Xft 演示客户端：`libXft-devel`、`freetype-devel`、`fontconfig-devel`、`libXrender-devel`。
- 编译命令：`gcc -O2 -I$SYSROOT/usr/include -I$SYSROOT/usr/include/freetype2 -o tools/ime_gui_demo tools/ime_gui_demo.c -lX11 -lXtst -lXft -lfontconfig -lfreetype`。
- 运行演示客户端时须设 `FONTCONFIG_FILE=$RUN/fonts.conf FONTCONFIG_PATH=$RUN`，否则 Xft 用系统 fontconfig（无文泉驿）→ 中文渲染成方块。

## 6. 环境限制：xterm 无法运行（已记录，非本项目缺陷）

最初想用真实 `xterm` 作为目标应用，但 **xterm 启动即退**：

```
/workspace/sysroot/usr/bin/xterm: Cannot chown /dev/pts/7 to 0,5: Invalid argument
```

原因：xterm 的 pty 初始化会对从 pty 从设备 `/dev/pts/N` 执行 `chown(uid=0, gid=5)`（gid 5 = `tty`）。在本 bwrap 用户命名空间里 **gid 5 未被映射**，`chown` 返回 `EINVAL`，xterm 视其为致命错误并退出（加 `-e`、不带 `-e`、`-version` 行为一致，说明是 pty 初始化阶段失败）。

该问题**无法通过 xterm 参数绕过**。故演示改用**自建的真实 X 客户端窗口**——它同样经 XIM 收键、同样用 fontconfig 渲染中文，等价于"任意应用渲染 IME 提交文本"，能真实反映桌面输入体验。
