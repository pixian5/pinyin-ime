# 移除候选窗首选全拼标注 + 全拼→简拼动态记忆

- 日期：2026-10-19 15:00
- 版本：v0.9.112
- 环境：Ubuntu 24.04 x86_64，公网 IP 110.42.235.24

## 背景

用户反馈两个点：
1. 候选窗**第一项后面跟着这个词的完整全拼**（如 `1.你好 nihao`），其他项没有，要求删除。
2. 优化：用户输入全拼后，把该词的**简拼记忆下来**，下次输入简拼时优先（置顶或加权）。

## 需求 1：移除首选候选的全拼标注

### 根因

v0.9.90 引入「首选候选显示拼音标注」功能，在 `pinyinime.cpp` 的候选渲染里：
```cpp
Text candText(cands[displayIdx].toString());
if (i == begin && page_ == 0) {
    std::string candPy = context_.candidateFullPinyin(displayIdx);
    if (!candPy.empty()) candText.append(" " + candPy);
}
```
导致候选窗第一项显示 `你好 nihao`，而其他项没有。

### 修复

删除上述 `if (i == begin && page_ == 0)` 块，候选文本直接 `cands[displayIdx].toString()`。

### 验证

在 :1 云桌面用 `ime_gui_demo` 输入 `nihao`，截图候选窗，PIL 定位差异区域、裁剪放大 3 倍后 tesseract OCR：
```
ni hao
1.你好 2.拟好 3.你号 4.拟号 5.逆好 6.泥好 7.尼好 8.你耗 9.逆号
```
第一项为 `1.你好`，**不再带 `nihao`**。

## 需求 2：全拼→简拼动态记忆

### 设计

用户输入**完整全拼**并选词成功后，把「全拼首字母缩写 = 词」记忆下来，下次输入该简拼时 boost 到首位。

### 实现

**`cpp/abbr_presets.h`**：
- 把 `user_abbr_map()` 拆成 `mutable_user_abbr_map()`（可变，首次加载文件）+ 只读的 `user_abbr_map()`。
- 新增 `remember_abbr(key, word)`：把 `key=word` 写入内存 map，并追加到 `~/.config/pinyin-ime/abbr.txt`（与 CLI 共享同一用户简拼文件）。
- 补充 `<filesystem>`、`<system_error>` 头文件。

**`fcitx5-addon/pinyinime.cpp`**：
- 新增辅助函数 `try_remember_abbr_from_full(preedit, word)`：
  - 取紧凑拼音（去 `'`/空格），仅当 `is_valid_pinyin(compact)` 为真（确认是全拼）且长度≥2 时继续。
  - 按 `'` 切分音节（libime 的 preedit 如 `zhong'guo`），取每音节首字母组成简拼。
  - 音节数≥2 时调用 `pinyin_ime::remember_abbr(abbr, word)`。
- 在 `selectCandidate` 开头保存原始 `context_.preedit()`，在 `context_.selected()` 且 `text` 非空时调用记忆。

### 验证

1. 清空 `~/.config/pinyin-ime/abbr.txt`。
2. 输入 `zhongguo` 按空格 → 上屏"中国"，abbr 文件出现 `zg=中国`。
3. 输入 `zg` 按空格 → 上屏"中国"（记忆被 boost）。
