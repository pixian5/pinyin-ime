## 关键坑（复现须知）

1. **只读 /usr**：`dnf install` 不可用 → `dnf --downloadonly` + `rpm2cpio` 解到 `$SYSROOT`；
   RPM 的 `.pc` 硬编码 `/usr` → 用 `scripts/fix_sysroot_pc.sh` 批量改写（185 个）。
2. **Xvfb**：编译期路径 `/usr/bin`、`/usr/share/X11/xkb` 需二进制补丁为 `/xr/…`（`/` 可写）。
3. **dbus-daemon**：需 `--config-file=$SYSROOT/usr/share/dbus-1/session.conf` 且 `LD_LIBRARY_PATH` 指向
   前缀 libdbus（系统版私有符号不兼容）→ 仓库已提供 `scripts/sandbox-bin/` wrapper，
   运行测试前 `export PATH=$PWD/scripts/sandbox-bin:$PATH`。
4. **GTK3 im module 编译**：fcitx5-gtk 5.1.7 `utils.h` 缺 `<cstdlib>`（gcc10 下 `std::free` 报错）。
5. **conda Qt 必须配 conda gcc**（与 GTK 模块用系统 gcc 相反，ABI 要与 Qt 对齐）。
6. **`grep -q` + `pipefail`**：首个匹配后提前关管道，fc-list 收 SIGPIPE 退出 141 会被误判为「没装」。
7. **后台 fcitx5 需 `setsid/nohup`**，否则随 shell 退出被 SIGHUP 带走。
8. **沙箱 HOME=/workspace**（不是 /root），用户字体/配置都在其下。
9. 沙箱中部分 fcitx5/历史进程**无法被 kill**（docs 已记），换新 DISPLAY（:97/:98）隔离验证。

- RPM 前缀 `/workspace/xroot`：xorg-x11-server-Xvfb、dbus、gtk3(-devel)、libxcb/xkbfile、
  X11 devel 头、iso-codes、xorg-x11-utils、fonts-dejavu 等

- 字体：文泉驿微米黑（aliyun debian 镜像 `fonts-wqy-microhei`）
- 源码：fcitx5 5.1.23、fcitx5-gtk 5.1.7、fcitx5-qt 5.1.4（均走 gh-proxy.com）

## 免 CLI 交付说明

`scripts/install_desktop.sh` 生成：

- `$PREFIX/bin/fcitx5-pinyin` 启动器（自带 env.sh）
- `~/.config/autostart/pinyin-ime.desktop`（登录自启）
- `~/.config/environment.d/90-pinyin-ime.conf` + `~/.xprofile`（GTK/Qt/XIM 环境变量）
- `~/.config/fcitx5/profile`（默认输入法 = pinyinime）
- 中文字体自动安装 + 8 项自检
