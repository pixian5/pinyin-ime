# 数据文件归属重构 + 可卸载 runtime（v0.9.190）

> 2026-11-26 19:05 · 豆包 · 版本 0.9.189 → 0.9.190

## 1. 决策：rpm/deb 不再自带 LM/词典

v0.9.189 的安装测试已经证明自带数据会与发行版 `libime-data` 撞 `/usr/share/libime/sc.dict`（dpkg 必须 `--force-overwrite` 才能装）。本轮按「依赖系统数据」落地：

- `pinyin-ime.spec`：新增 `Requires: libime-data`，`%files` 移除 `zh_CN.lm`/`sc.dict`；
- deb：`Depends: fcitx5, libime, libime-data`；
- 体积：deb 22,734,452 B → **999,178 B**；rpm 22,744,028 B → **1,008,544 B**（约 22.7MB → 1MB）；
- **runtime 包保持自包含**（容器/云桌面常常没有 libime-data），`BUILD-INFO.txt` 标 `(self-contained)`；需要自包含 rpm/deb 时设 `BUNDLE_DATA=1`。

`stage_rootfs` 增加第三参数 `with_data`，rpm/deb 传 0、runtime 传 1；数据文件缺失校验也只在实际需要的模式下进行。

## 2. 新增：便携包卸载脚本

`install.sh` 安装后把文件清单写到 `/usr/share/doc/pinyin-ime/installed-files.txt`；`uninstall.sh` 按清单反向删除，并且**跳过任何被 dpkg/rpm 系统包占用的文件**（避免误删 `libime-data` 的 `sc.dict`），最后清空目录、`fcitx5 -r`。

## 3. 新增：打包前 CLI 版本一致性校验

改 `VERSION` 后忘记重编 CLI，会出现「包新、二进制旧」：v0.9.190 第一轮打包就装上了一个 `--version` 仍报 0.9.189 的 CLI。现在 `build_packages.sh` 会执行 `$CLI --version` 与 `VERSION` 对比，不一致直接失败；交叉打包（二进制无法在当前机器执行）自动跳过。注意：仅重跑 `cmake --build` 不够，**必须重新 configure** 才会重新生成 `version.h`。

## 4. 验证（chroot x86_64）

| 项 | 结果 |
| --- | --- |
| deb 正常安装（无 force） | `Status: install ok installed`，`Version: 0.9.190`，`Depends: fcitx5, libime, libime-data` |
| deb 包内文件 | 6 个（CLI / addon / addon conf / 配置模板 / inputmethod / README），无 LM/sc.dict |
| `pinyin_ime_cli --version` | `0.9.190`（与包版本一致） |
| 解码（不传 `--lm/--dict`） | `nihao→你好`、`woaibeijing→我爱北京`、`zhongguorenmin→中国人民` |
| rpm `rpm -i` | 装入 6 个文件 + build-id，CLI 0.9.190 可选码，`rpm -e` 干净卸载 |
| runtime 安装→卸载往返 | 装后 CLI/addon/LM 就位、可解码；卸载后 CLI/addon 删除，`sc.dict` 保留 |
| `sha256sum -c SHA256SUMS_v0.9.190` | 三项 OK（rpm/deb/runtime） |

## 5. 升级风险（务必写进发布说明）

**从 0.9.189（自带数据版）升级到 0.9.190 会删掉发行版的 `/usr/share/libime/sc.dict`**：0.9.189 曾覆盖 `libime-data` 的文件，dpkg 在新版本不再包含该文件时会把它当作「旧包文件」删除，`libime-data` 并未重新安装，于是系统里就没有词典了（实测 CLI 报「找不到系统词典」）。

修复：`sudo apt-get install --reinstall libime-data`（或重装 `libime`）。0.9.190 自身不会再产生这个问题。

## 6. 遗留

- 真机 fcitx5 GUI 加载仍未验证；
- `uninstall.sh` 依赖清单文件，若用户先手工删了清单则无法卸载（会提示找不到清单）；
- runtime 包没有签名，`sha256sum` 清单需与包一起分发。
