## 4. 经验

1. **`project(... VERSION ...)` 只接受字面量**。想用变量必须提早在 `project()` 之前 `file(STRINGS ...)`，否则 CMake 语法都过不去。项目里 `project(VERSION 0.9.126)` + 末尾 `set(... ${PROJECT_VERSION})` 这个组合，是把“唯一来源”覆盖掉的典型写法。
2. **“显式反忽略”（`!ip.txt`）比不忽略更危险**：它会让后续任何宽规则失效，且看起来像“有意为之”，掩盖了真实风险。
3. **删除入库二进制不等于禁止入库**：还要在 `.gitignore` 里写规则，并在 CI 里用 `file` 判定 ELF，否则下一次构建又会被 `git add -A` 带进去。
4. **CI 门禁要选“零依赖”的测试**：`quick_input_test` 是纯 C++，不依赖 libime，任何 runner 都能跑；这正是它适合做第一道门禁的原因。
