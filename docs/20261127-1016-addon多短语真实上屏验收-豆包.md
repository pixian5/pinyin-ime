# addon 多短语真实上屏验收（v0.9.200）

## 为什么补

此前 addon 的真实桌面验证只敲了 `nihao` 一句，只能证明“能加载、能出候选、能上屏一个字”，证明不了候选索引映射、整句首选和空格提交在多个输入下都正确。CLI 侧有 42 例快照，addon 侧几乎没有对应覆盖。

v0.9.200 把运行时冒烟的短语参数化，并新增多短语验收脚本；这不是全量评测，而是真实用户入口的回归门禁。

## 实现

- `scripts/test_runtime_fcitx5.sh`：
  - 新增 `PINYINIME_TEST_INPUT`（默认 `nihao`）和 `PINYINIME_TEST_EXPECT`（默认 `你好`）；
  - 内部 GTK3 测试窗口仍由 xdotool 真实敲键，空格上屏后读取 Entry 文本；
  - 断言从写死「你好」改为动态期望，默认行为不变。
- `scripts/test_addon_phrases.sh`：
  - 逐个短语启动私有 Xvfb + 私有 HOME + dbus-run-session 的 fcitx5；
  - 每个短语都要求“6 通过、0 失败、0 跳过”，缺依赖不算通过；
  - 覆盖 8 句：`nihao`、`shijian`、`zhongguo`、`beifang`、`xianzai`、`zhongguorenmin`、`jintiantianqihenhao`、`qinghuadaxue`。
- CI 新增 `addon-acceptance` job：下载 `package` 产物，安装 deb，再装 fcitx5 / GTK3 / Xvfb / xdotool / python3-gi，跑同一脚本。

## 结果

本地 Ubuntu 24.04 chroot（fcitx5 5.1.7 + GTK3）：

```
nihao → 你好
shijian → 时间
zhongguo → 中国
beifang → 北方
xianzai → 现在
zhongguorenmin → 中国人民
jintiantianqihenhao → 今天天气很好
qinghuadaxue → 清华大学
addon 多短语验收：8 通过，0 失败，0 跳过
```

这组用例同时覆盖了：
- 单字/双字常用词；
- 有重排后容易变的 `shijian`、`beifang`；
- 消歧词 `xianzai`；
- 长句 `jintiantianqihenhao`；
- 专有名词 `qinghuadaxue`。

## 已知限制

- 8 句是抽样，不是 1200 句 addon 全量评测；addon 默认 `nbest=45` 的整体首选/翻页成本仍未测。
- 依赖真实 Xvfb + fcitx5 + GTK3，CI 失败时要先区分“依赖缺失”与“输入法回归”；脚本用“6 通过、0 跳过”避免把 SKIP 当成 PASS。
- 只验证空格选首选，不验证数字选词、翻页、云候选和用户学习。
- `womenzaiyonglibimezuoceshi` 这类中英混排仍是已知弱项（CLI 快照当前也是「我们在用礼毕么做测试」），没有塞进验收用例，避免把错误行为锁成期望。
