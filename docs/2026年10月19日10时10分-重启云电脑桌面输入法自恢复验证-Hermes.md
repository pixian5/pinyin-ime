# 2026年10月19日10时10分-重启云电脑桌面输入法自恢复验证-Hermes

## 本轮目标

重启云电脑（XFCE 桌面会话），验证 pinyinime 输入法是否通过 XDG autostart 自动恢复，并在重启后的桌面上做真实输入测试。

## 一、云电脑桌面结构

- X 显示：`Xvfb :1`（1440x900，PID 独立）
- 桌面会话：`dbus-run-session -- /usr/bin/startxfce4` → `xfce4-session` → `xfwm4` + `xfce4-panel`
- 远程访问：x11vnc（5900/5901/5903）+ websockify（6080，noVNC 网页）
- 会话 DBus：从 `xfce4-session` 进程环境读取 `DBUS_SESSION_BUS_ADDRESS`

## 二、配置开机自启动（XFCE XDG autostart）

创建 `~/.config/autostart/fcitx5.desktop`：

```ini
[Desktop Entry]
Type=Application
Name=Fcitx 5
Name[zh_CN]=Fcitx 5 输入法
Comment=Start Input Method
Exec=env XMODIFIERS=@im=fcitx GTK_IM_MODULE=fcitx QT_IM_MODULE=fcitx FCITX_ADDON_DIRS=/home/agentuser/.local/lib/fcitx5:/usr/lib/x86_64-linux-gnu/fcitx5 fcitx5 -d
Icon=fcitx
Terminal=false
Categories=System;Utility;
X-GNOME-Autostart-enabled=true
```

XFCE 4 通过 `~/.config/autostart/*.desktop` 支持 XDG autostart，桌面会话启动时会自动执行。

## 三、重启云电脑（清理 + 重启桌面会话）

1. 杀残留 fcitx5：`pkill -9 -x fcitx5`
2. 杀旧桌面会话（注意用 `-x` 精确匹配进程名，避免 `-f` 误杀包含关键字的 shell 自身）：
   ```bash
   for pat in xfce4-session dbus-run-session xfwm4 xfce4-panel; do pkill -9 -x "$pat"; done
   ```
3. 重启桌面会话：
   ```bash
   setsid dbus-run-session -- /usr/bin/startxfce4 > /tmp/xfce-restart.log 2>&1 < /dev/null &
   disown
   ```

**关键点**：`Xvfb :1` 是独立进程，杀桌面会话不会影响它；VNC/noVNC 服务 attach 到 :1，桌面重启后自动重连。

## 四、重启后自恢复验证

- 新 `xfce4-session`（PID 2770440）由 `dbus-run-session`（2770438）拉起。
- **fcitx5 自动启动成功**（PID 2770524），通过 XDG autostart 生效。
- fcitx5 正确接入新会话 DBus（`unix:path=/tmp/dbus-e1MVoVsO4x,...`），并注册 `org.fcitx.Fcitx5`。
- 配置完好：`~/.config/fcitx5/profile` DefaultIM=pinyinime；`~/.config/fcitx5/conf/pinyinime.conf` EnableCorrect=True。

## 六、踩坑记录

- `pkill -9 -f "fcitx5 -d"` 会把命令行里含该字符串的 bash 自身也杀掉 → 用 `-x` 精确匹配进程名。
- GTK 测试客户端默认 30 秒超时，多用例测试务必传更长超时（如 `gtk_ime_test_client 120`）。
- 每个用例前按 Escape 清空预编辑；焦点窗口需 `xdotool windowfocus` 先行聚焦。
- 判断上屏用"日志行数增量"（before/after），避免读到旧日志。
