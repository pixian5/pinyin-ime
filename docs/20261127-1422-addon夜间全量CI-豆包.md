# addon 1200 句夜间全量评测（v0.9.205）

## 改了什么

- `.github/workflows/ci.yml` 增加 `addon-full-eval` job：`schedule`（每周一 18:00 UTC / 周二 02:00 CST）和 `workflow_dispatch` 时，在真实 Ubuntu 24.04 + fcitx5 + Xvfb + GTK3 环境跑完整 1200 句 addon 上屏评测。
- 该 job 依赖 `package` 产物，安装 deb 后调用 `scripts/eval_addon_batch.sh`，上传 `report.md` / `summary.json` 作为构建产物。
- 评测失败或报告缺失不阻塞 push 的四个常规 job；`if: always()` 只负责尽量保留证据。
- 手动触发入口：GitHub Actions → CI → Run workflow。

## 为什么不是 push 每次都跑

1200 句在本地约 15 分钟，按当前 GitHub runner 和 xdotool 节奏还会更久；push 每次跑会拖慢反馈。夜间/手动跑既保留真实入口的完整回归，又避免把常规 CI 拖成半小时。

## 验证边界

- 本轮只改 CI 配置；本地无法完整复现 Actions runner 的 `schedule`，需要推送后手动 `workflow_dispatch` 跑一次确认。
- 现有 push 仍只跑 8 句 `addon-acceptance`；夜间 job 是补充，不替代。
- 没有设置准确率硬门禁，先观察报告稳定性和耗时；确认稳定后再加“Top1 掉超过 1pp 失败”。
