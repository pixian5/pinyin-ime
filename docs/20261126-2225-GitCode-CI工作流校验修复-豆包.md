# GitCode CI 工作流校验修复（2026-11-26 22:25）

## 背景

v0.9.195 推送后，GitCode 远端流水线长期显示失败。此前只在浏览器里看到「页面找不到或无权限」，没有拿到真实原因。本次通过 GitCode 仓库页实际调用的 `web-api` 运行列表接口，第一次读到 5 条真实运行记录，全部是 `VALIDATION_ERROR`，说明流水线从未进入 runner 阶段。

接口（只读，公开仓库可匿名访问）：

```text
POST https://web-api.gitcode.com/api/v2/projects/laotongtian%2Fpinyin-ime/actions/workflow-runs/list
Content-Type: application/json

{"page":1,"per_page":20,"record_type":"physical"}
```

返回的 `message` 字段里是完整校验诊断。修复前 5 条记录的核心错误：

1. `jobs[build-eval].name` 含 `+`，GitCode 只允许字母、数字、空格及 `- _ , ; : . / ( )`。
2. `jobs[static].runs-on`、`jobs[unit].runs-on` 使用 `euleros-2.10.1`；单字符串形式只允许 `default`、`ubuntu-latest`、`euler-latest`、`ubuntu-24`、`ubuntu-22`。
3. `steps[0].name` 为空：checkout 步骤只有 `uses`，没有 `name`。
4. `uses: checkout-action@0.0.1` 插件不存在；GitCode 官方写法是 `uses: checkout`。

## 修复内容

`.gitcode/workflows/ci.yml`：

- 三个 job 的 `runs-on` 统一改为 `ubuntu-latest`（Ubuntu 24.04，apt/dpkg，满足 `ci_build.sh` 的依赖安装）。
- checkout 步骤改为：

  ```yaml
  - name: Checkout
    uses: checkout
  ```

- `build-eval` 的 job 名从 `Build + eval (Ubuntu 24.04)` 改为 `Build and eval (Ubuntu 24.04)`，去掉非法 `+`。
- `static`、`unit`、`build-eval` 的所有 step 都有非空 `name`。
