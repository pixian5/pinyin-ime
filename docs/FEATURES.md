## 模糊音规则

| 规则 | 示例 |
|---|---|
| 平翘舌 | z↔zh, c↔ch, s↔sh |
| 前后鼻音 | an↔ang, en↔eng, in↔ing |
| n/l 混淆 | nan↔lan, ni↔li |
| f/h 混淆 | fa↔ha (可选) |
| 键盘纠错 | senme→shenme, zongguo→zhongguo |

## 准确率

| 语料 | 句级 | 字级 |
|---|---|---|
| 日常40句 | 97.5% | 96.6% |
| 基准20句 | 100% | 100% |
| E2E 40句 | 95.0% (38/40) | - |
| 新闻+百科200句 | 32.0% | 83.9% |

> 新闻+百科准确率较低是因为政治/专有名词词汇不在 LM 覆盖范围内，
> 日常对话场景表现优秀。
