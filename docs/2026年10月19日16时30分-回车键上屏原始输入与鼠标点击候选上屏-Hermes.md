# v0.9.115 回车键上屏原始输入 + 鼠标点击候选上屏

日期：2026年10月19日 16时30分
版本：0.9.115
模型：Hermes

## 问题背景

用户反馈两个需求：
1. **回车键上屏为用户原始输入**：当前回车与空格行为相同（都是「上屏焦点候选」），用户希望回车直接上屏输入的原始拼音串（不选中文候选）。
2. **鼠标点击哪个词也能上屏**：候选窗里的词用鼠标点击没有反应。

## 根因分析

### 回车与空格同行为
`keyEvent` 里空格与回车走同一分支：
```cpp
if (event.key().check(FcitxKey_space) ||
    event.key().check(FcitxKey_Return)) { ... selectCandidate(...) ... }
```

### 鼠标点击无反应
候选列表用的是官方 `DisplayOnlyCandidateWord`：
```cpp
class DisplayOnlyCandidateWord : public CandidateWord {
    void select(InputContext *) const override {}   // 空实现！
};
```
`select()` 是空实现 → classicui 把点击事件派发给 `CandidateWord::select()`，什么都不做。

## 解决方案

### 1. 回车 / 空格分离（pinyinime.cpp）

在空格/回车分支前新增独立的回车处理：把 `ctx.preedit()` 里的字母与隔音符取出（去掉空格），
作为「用户原始输入」上屏，然后 `reset()`；无拼音时不消费（交给应用换行）。

```cpp
if (event.key().check(FcitxKey_Return)) {
    if (!ctx.empty()) {
        std::string raw;
        for (char c : ctx.preedit())
            if ((c >= 'a' && c <= 'z') || c == '\'') raw.push_back(c);
        if (raw.empty()) raw = state->rawInput_;
        state->commitText(raw);
        state->reset();
        event.filterAndAccept();
    }
    return;
}
```
空格分支保持原语义（上屏焦点候选）。

### 2. 可点击候选词 PinyinCandidateWord（pinyinime.cpp）

新增 `PinyinCandidateWord`，`select()` 回调 `state_->selectCandidate(显示索引)`：
```cpp
class PinyinCandidateWord : public CandidateWord {
public:
    PinyinCandidateWord(Text text, PinyinIMEState *state, size_t dispIdx)
        : CandidateWord(std::move(text)), state_(state), dispIdx_(dispIdx) {}
    void select(InputContext *) const override { state_->selectCandidate(dispIdx_); }
private:
    PinyinIMEState *state_;
    size_t dispIdx_;
};
```
候选追加时用 `PinyinCandidateWord` 替代 `DisplayOnlyCandidateWord`，显示索引约定与数字键/空格
一致：`page*pageSize + 页内显示位`（含 boost 插入词占位）。这样「点击第 N 项」与「按数字键 N」
完全等价。

### 3. 移除未使用的 InputMethodEntry 参数（重构）

`selectCandidate`/`refreshUI`/`updateUI`/`flipPage`/`commitPunctuation`/`undoLastCommit` 六个方法
原本都带 `const InputMethodEntry &entry` 参数但从未使用（`FCITX_UNUSED(entry)`）。鼠标点击回调
（`select()`）拿不到 entry，故把这些参数全部移除；`keyEvent` 的 entry 参数加 `FCITX_UNUSED`。

## 说明

- 回车上屏的「原始输入」是 preedit 的字母形式（含隔音符 `'`，去空格），如输入 `ni'hao` 回车
  上屏 `ni'hao`；退格后也准确（始终取当前 preedit）。
- 鼠标点击与数字键共用同一套显示索引，因此 boost 交换显示、boost 插入词、翻页后的候选都能
  正确点击上屏。
- 无拼音时空格/回车都不消费，交给应用（换行/空格）。
