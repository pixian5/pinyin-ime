# 字符 4-gram 重排落地（v0.9.207）

## 背景

v0.9.204 已量化 addon 候选池：Top1 30.25%、Top5 45.17%、Top10 49.83%，Top5 比 Top1 高 14.92pp。主线因此从“扩召回”转为“把已在第一页的正确答案重排到 Top1”。

离线实验（1200 句 × 45 候选，`nbest45_dump.tsv`）已验证：

- 现有 trigram + alpha 0.25：CLI Top1 **30.33%**
- 4-gram + stupid backoff + alpha 0.25：CLI Top1 **31.58%**
- 5-gram 明显更差（28.75%），不做
- 4-gram 与 trigram 插值最高约 30.08%，不如纯 4-gram

## 实现

### 模型格式 v2

`cpp/char_lm.h/.cpp`：

- 新增 `QuadCtx { p3, p2, p1, total }`、`QuadEntry { p3, p2, p1, ch, count }`；
- 版本 `kVersion = 2`，加载允许 v1/v2；v1 没有 4-gram 段，`score()` 自动回退 trigram；
- 新增 `logQuadProb()`：
  - 命中 4-gram：`log(c4 / t4)`
  - 回退 3-gram：`log(0.4 * c3 / t3)`
  - 回退 2-gram：`log(0.4 * c2 / t2)`
  - 回退 unigram：`log(0.4 * max(c1, 0.1) / N)`
- 短候选保护：UTF-8 字节数 `< 18`（约 6 个汉字）仍走 trigram，避免 4-gram 在极短文本上过拟合。实测 42 例 CLI 快照除版本头外零变化，`年轻`、`加入什么` 等短词未被改坏。
- 低频剪枝：4-gram 条目只保留出现 `>=2` 次者。离线扫描 1200 句候选池，Top1 仍 31.58%，但 4-gram 上下文从 197,063 降到约 10,734，模型从 6.6MB 压到 **3.1MB**。

### 训练器

`scripts/train_char_lm.py`：

- `VERSION = 2`，新增 4-gram `quad` 计数；
- 边界 `p3=p2=p=<s>`，句末 `</s>` 同时计入 3/4-gram；
- 二进制追加 `quadgram_ctx_n` + `quadgram_ctx`、`quadgram_entry_n` + `quadgram_entry`；
- 训练语料仍为 `bench/clean_corpus.py` 的去重输出（12,130 句 / 257,455 字），不是原始 `bench/corpus`。

### 模型

`data/char_trigram.bin` 重训为 v2：

- 词表 3929、bigram 107,229、trigram 203,674；
- 体积 2,945,931 → **3,170,231 字节**（仅 +0.2MB；剪枝后）；
- 4-gram 上下文 10,734、条目 13,842，按 `packQuadCtx`、`packQuad` 排序，加载时二分查找。

## 结果

CLI nbest=45，1200 句 clean holdout：

| 域 | 句级 Top1 | 字级 |
|---|---|---|
| baike | 31.33% | 88.81% |
| news | 41.00% | 89.52% |
| recent | 34.67% | 87.30% |
| wiki | 19.33% | 79.97% |
| **合计** | **31.58%** | **86.40%** |

对比 v0.9.206 的 30.33% / 86.24%：Top1 +1.25pp，字级 +0.16pp。

Top-k/MRR：Top1 31.58%、Top3 41.42%、Top5 45.42%、Top10 49.00%、MRR 0.377、平均命中排名 3.68、翻页率 38.72%、未命中 557/1200。

## addon 全量

已安装 v2 模型到 `/usr/share/pinyin-ime/char_trigram.bin`，真实 fcitx5 + Xvfb + GTK3 全量 1200 句：

| 版本 | Top1 | Top5 | Top10 | MRR | 字级 | P50 | P95 | P99 |
|---|---|---|---|---|---|---|---|---|
| v0.9.204（trigram） | 30.25% | 45.17% | 49.83% | 0.3689 | 86.24% | 503.8ms | 646.6ms | 711.8ms |
| v0.9.207 未剪枝 | 30.08% | 45.67% | 49.42% | 0.3699 | 86.39% | 502.8ms | 603.8ms | 694.5ms |
| **v0.9.207 剪枝** | **30.17%** | **45.92%** | 49.50% | **0.3707** | **86.42%** | 502.6ms | 643.6ms | 708.8ms |

剪枝版相对 v0.9.204：Top1 **-0.08pp**（1 句，噪声级）、Top5 +0.75pp、MRR +0.0018、字级 +0.18pp。结论：4-gram 的 +1.25pp 只在 CLI 整串路径成立，逐键 addon 基本持平；不能把 CLI 增益直接当成用户上屏增益。

## 门禁与风险

- `scripts/ci_build.sh` 已通过：clean 语料重训与 `data/char_trigram.bin` 字节一致（3,170,231 字节），42 例快照 0 差异，nbest=10 holdout Top1 30.92% / 字级 86.06%。
- 模型体积 +3.9MB，deb/rpm 会相应增大；这是当前已知代价，尚未做量化压缩。
- 4-gram 只改善“候选已在池内”的排名；未命中仍是 557 句，下一阶段不能只盯着 Top1。
- addon 逐键路径没有同步 +1.25pp；下一步不要继续加 n-gram 阶数，应做 addon 专用的保守重排（原 top1 先验/换位门限）并单独评测。
