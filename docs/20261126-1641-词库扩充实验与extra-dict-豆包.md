# 词库扩充实验：为什么"加词"救不了准确率（v0.9.181）

> 撰写：2026-11-26 16:41，豆包。对应提交 v0.9.181。
> 前置：[20261126-1633-候选召回上限与准确率路线-豆包.md](20261126-1633-候选召回上限与准确率路线-豆包.md)（路线 B 就是这里被否掉的）。

## 1. 先造一个能加载外部词库的入口

原来的 `--dict-import F` **不是** libime 词典，它写的是 `~/.config/pinyin-ime/abbr.txt`（简拼映射），走的是我们自己的 `lookup_pinyin_boost`，跟解码无关——这一点很容易误会，写文档时特意点了出来。

新增 `--extra-dict F`：直接 `ime.dict()->load(PinyinDictionary::UserDict, F, PinyinDictFormat::Text)`，把词加进 libime 的 UserDict 索引，参与真正的解码。

**格式坑（实测两次才通）**：libime 文本词典是 `词<空格>拼音<空格>cost`，且**各音节用单引号连接**：

```
汪菊川 wang'ju'chuan 0.0        ✅ 正确
汪菊川<TAB>wang ju chuan         ❌ 被跳过（按空格切出 4 个 token，不是 2/3 个）
汪菊川<TAB>wangjuchuan           ❌ 日志 "Failed to parse line"
```

依据是 libime 源码：`loadTextImpl` 按空白切 token（只接受 2 或 3 个），而 `PinyinEncoder::decodeFullPinyin` 输出用 `'` 连接音节。用 `save(Text)` 回读验证：正确格式能 5 万字全量落库、0 行跳过。

## 2. 实验设计

- 词源：rime-ice 的 `base/ext/others`，筛 2–4 字纯中文词、拼音可转纯 ASCII（`ü→v`、去声调去数字），按权重取前 **5 万**词。
- 两个变量分开测，避免"改了两件事不知道是谁起的作用"：
  1. **全量 5 万词**（含系统词典已有的）；
  2. **只补缺失**：先把系统词典 dump 成文本（`sc.dict` → 209,269 条），按 `(词, 拼音)` 去重后只剩 **12,315** 条新增。
- 评测：同一套 1200 句 holdout、同机、同 LM/dict、`--batch --top1`。

## 3. 结果

| 配置 | 句级 | 字级 | 总耗时 |
|---|---|---|---|
| 基线（v0.9.179） | 26.67% | **84.26%** | 68s |
| + 全量 5 万词 | 26.67% | **83.80%（−0.46pp）** | **138s（翻倍）** |
| + 仅补缺失 12,315 条 | 26.75% | **84.29%（+0.03pp）** | 67s |

分域看，"仅补缺失"这组 wiki 字级 76.38% → 76.45%，baike 86.20% → 86.25%——都在噪声范围内。

## 4. 为什么加词没用

1. **重叠率极高**：5 万常用词里 **37,685 条（75.4%）系统词典本来就有**。`sc.dict` 有 20.9 万条，常用词覆盖已经不错，"缺词"不是主要矛盾。
2. **加词会把同音噪声放大**：全量导入时，每条词 cost 都设 0.0，等于给所有候选同等"优待"，同音词变多，解码器更容易选错 → 字级掉 0.46pp，同时候选搜索变慢一倍。
3. **剩余错误是排序问题**：上一轮的召回上限已经说清楚——前 10 个候选里含正解 46.08%、候选内字级上限 90.21%，而首选只有 27.83% / 84.26%。也就是说正解**常常在候选里**，只是没排到第一。这件事加词解决不了。

## 5. 结论与下一步

- **路线 B（扩词典）判定无效**，不再投入。词库不是瓶颈，排序才是。
- 优先级改为：**C 重排序**（在 nbest=10 上用上下文/句式/长度/词典频次等特征重排，把 27.83% 往 46.08% 的潜力吃，字级往 90.21% 推）→ **A 换/训 LM**（唯一能把句级天花板抬过 46% 的手段）。
- `--extra-dict` 保留为功能（第三方词库/专业词表可以用），但**默认不加载**，也不随包分发任何第三方词库（许可证与体积都不合适）。

## 6. 复现命令

```bash
# 1) 造词表（rime-ice 需自行下载，不入库）
#    格式：词<空格>音节'音节<空格>cost
# 2) 只补系统词典没有的词：先把系统词典 dump 成文本再比对
ddump /usr/share/libime/sc.dict /tmp/sys.dict        # 见 docs 附的探针用法
# 3) 评测
pinyin_ime_cli <lm> <dict> --batch holdout.txt --top1 --user-data /tmp/u --extra-dict /tmp/extra.dict
```

`ddump` 探针（临时程序，未入库）：`PinyinDictionary::load(SystemDict,…,Binary)` 后 `save(SystemDict,…,Text)`，用来核对词表重叠与格式。
