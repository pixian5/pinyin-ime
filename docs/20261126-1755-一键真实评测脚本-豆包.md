# 一键真实评测脚本（v0.9.184）

> 2026-11-26 17:55 · 豆包 · 版本 0.9.183 → 0.9.184

## 1. 问题

真实评测依赖 Linux + libime，而开发机是 macOS，过去六个版本的评测都是「手工敲一串命令」：

```bash
sudo rsync -a --delete --exclude .git . /home/user/chroots/noble24/src/
sudo chroot /home/user/chroots/noble24 bash -c 'cmake -S /src/cpp -B /tmp/build && make -C /tmp/build pinyin_ime_cli'
sudo chroot /home/user/chroots/noble24 bash -c 'cd /src && python3 bench/eval.py --engine cli ...'
sudo cp /home/user/chroots/noble24/tmp/eval_out_* bench/results/
```

漏一步就拿不到数、或者拿旧产物出数。这类「只在脑子里」的流程本身就是可信化的漏洞。

## 2. 改动

新增 `scripts/eval_chroot.sh`：

- 参数：`--skip-build`（复用已有二进制）、`-h`；环境变量 `CHROOT` / `SRC` / `BUILD` / `LM` / `DICT` 可覆盖默认；
- 流程：同步仓库（`--delete`，排除 `.git` 与 `bench/results`）→ chroot 内 CMake + make `pinyin_ime_cli` → `bench/eval.py --engine cli --baseline bench/baseline.json` → 报告回写到 `bench/results/<VERSION>/`；
- 退出码：`0` 达标、`2` 低于基线（句级 −1.0pp / 字级 −0.5pp）、其它为构建或环境错误；
- 前置检查：chroot 目录、`zh_CN.lm` 是否存在，缺了直接报错退出，不会静默拿错数据。
