🔤 Xvfb 桌面拼音输入法实测

环境: Xvfb :99 + metacity + fcitx5 5.1.23 + pinyinime addon

链路: XTest按键 → XIM协议 → fcitx5 → pinyinime引擎 → 中文上屏

1. 初始桌面

xterm窗口已打开，等待输入

2. Ctrl+Space 激活输入法

拼音输入法已激活

3. 输入 n

preedit: n

4. 输入 ni

preedit: ni → 你

5. 输入 nih

preedit: nih

6. 输入 niha

preedit: niha

7. 输入 nihao（完整拼音）

候选窗口应显示: 1.你好 2.你号 3.昵好...

8. 按空格确认 → 你好

"你好"已上屏

9. 输入 zhongguo（preedit）

候选窗口显示中国相关候选

10. 空格确认 → 中国

"你好中国"已在屏幕上

11. 输入 shurufa（preedit）

候选窗口显示输入法相关候选

12. 空格确认 → 输入法

"你好中国输入法"已在屏幕上

13. 最终状态

xterm显示: 你好中国输入法
